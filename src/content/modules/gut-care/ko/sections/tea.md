# 차

> 아래 **하나만** 하루에 선택하세요. 여러 가지를 겹치지 마세요.

| 차·제품 | 권장량 |
|---------|--------|
| 설국화(雪菊花) | 하루 5~10알 |
| 팽대해(胖大海) | 하루 1알 |
| 나한과(罗汉果) | 주 1개 |
| 귀릉고 분말(龟苓膏粉) | 끓는 물에 삶음. 번거롭지만 화(火)를 내리는 효과가 뚜렷함 |

## 안내

차는 주로 청열·화(火)를 내리는 보조에 씁니다. 귀릉고 분말은 준비가 번거롭지만 저자 경험상 효과가 분명했습니다.

> 임신·수유 중이거나 만성 질환이 있으면 사용 전 의사와 상담하세요.
