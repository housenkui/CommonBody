# CommonBody 多语言（i18n）上线指南

> 目标：用户点击语言切换器，可在 **中文、英语、德语、日语、韩语、越南语、泰语、法语、西班牙语** 之间切换。  
> 项目现状：Vite + React + TypeScript + React Router + Markdown 内容  
> 文档版本：v1.1  
> 更新日期：2026-06-10

---

## 已确认决策

| 项目 | 决定 |
|------|------|
| **默认语言** | **中文（`zh`）** |
| URL 前缀方案 | 采用 `/:lang/...` |
| 中文 URL | **不带前缀**，如 `/`、`/modules/gut-care` |
| 其他语言 URL | 必须带前缀，如 `/en/`、`/de/`、`/es/` |
| `/zh/` 路径 | 301 重定向到无前缀的 `/`（避免重复） |
| 未翻译内容回退 | 目标语 → `en` → `zh` |

## 一、支持的语言

| 显示名称 | 语言代码 | 说明 |
|----------|----------|------|
| 中文 | `zh` | **默认语言**，当前全部内容 |
| English | `en` | 第一优先级翻译 |
| Deutsch | `de` | 德语 |
| 日本語 | `ja` | 日语 |
| 한국어 | `ko` | 韩语 |
| Tiếng Việt | `vi` | 越南语 |
| ไทย | `th` | 泰语 |
| Français | `fr` | 法语 |
| Español | `es` | 西班牙语 |

**语言代码采用 ISO 639-1**（两位小写），便于 URL、SEO、浏览器识别。

## 二、推荐整体方案

### 2.1 架构概览

```
用户点击语言切换器
        ↓
URL 变为 /en/modules/gut-care（或写入 localStorage + 跳转）
        ↓
┌─────────────────────────────────────────┐
│  UI 文案（导航、按钮、页脚）              │  → react-i18next JSON
│  长文内容（模块、故事、静态页）            │  → 各语言 Markdown 文件
│  元数据（title、description、模块标签）   │  → meta.json 多语言字段
└─────────────────────────────────────────┘
```

### 2.2 技术选型

| 用途 | 推荐方案 | 理由 |
|------|----------|------|
| UI 短文案 | **react-i18next** + **i18next** | React 生态成熟，支持懒加载语言包 |
| 路由 | **URL 前缀** `/:lang/...` | SEO 友好，可分享特定语言链接 |
| 长文 Markdown | **按语言分目录** | 与现有 `?raw` 导入方式一致，贡献者易 PR |
| 语言记忆 | **localStorage** + URL | 下次访问记住选择 |
| 机器翻译（可选） | 人工为主，DeepL/Google 辅助初稿 | 医疗内容必须人工审校 |

### 2.3 URL 设计（推荐）

```
https://commonbody.org/                       首页（中文，默认）
https://commonbody.org/modules/gut-care       中文护理模块
https://commonbody.org/en/                    英文首页
https://commonbody.org/ja/motivation          日文发心页
https://commonbody.org/de/modules/gut-care    德文护理模块
https://commonbody.org/es/modules/gut-care    西班牙文护理模块
```

**规则：**

- **默认语言 `zh`**：URL **不带** `/zh` 前缀，直接使用 `/`、`/motivation` 等
- 访问 `/zh/...` 时 **301 重定向** 到对应的 `/...`（统一 canonical）
- 非默认语言：必须带前缀 `/en/`、`/de/`、`/es/` 等
- 切换语言时：**保持当前页面路径**，只增删语言前缀

示例：用户在 `/modules/gut-care/fruits`（中文）点「English」→ 跳转到 `/en/modules/gut-care/fruits`

## 五、核心代码实现要点

### 5.1 安装依赖

```bash
npm install i18next react-i18next
```

### 5.2 语言列表配置（`src/i18n/languages.ts`）

```typescript
export const DEFAULT_LOCALE = 'zh'

export const LOCALES = [
  { code: 'zh', label: '中文', nativeLabel: '中文' },
  { code: 'en', label: 'English', nativeLabel: 'English' },
  { code: 'de', label: 'German', nativeLabel: 'Deutsch' },
  { code: 'ja', label: 'Japanese', nativeLabel: '日本語' },
  { code: 'ko', label: 'Korean', nativeLabel: '한국어' },
  { code: 'vi', label: 'Vietnamese', nativeLabel: 'Tiếng Việt' },
  { code: 'th', label: 'Thai', nativeLabel: 'ไทย' },
  { code: 'fr', label: 'French', nativeLabel: 'Français' },
  { code: 'es', label: 'Spanish', nativeLabel: 'Español' },
] as const

export type Locale = (typeof LOCALES)[number]['code']

export function isValidLocale(value: string): value is Locale {
  return LOCALES.some((l) => l.code === value)
}
```

### 5.3 路由改造思路

```tsx
// App.tsx 示意
<Route path="/:lang?" element={<Layout />}>
  <Route index element={<HomePage />} />
  <Route path="modules/:moduleId" element={<ModulePage />} />
  ...
</Route>
```

在 `Layout` 或路由守卫中：

1. 读取 `params.lang`
2. 若无 `lang`，用 `localStorage` 或默认 `zh`
3. 调用 `i18n.changeLanguage(lang)`
4. 非法 `lang` → 404 或重定向到默认语言

### 5.4 语言切换器行为

```typescript
// 伪代码
function switchLocale(newLocale: Locale) {
  const currentPath = location.pathname  // 如 /modules/gut-care 或 /en/modules/gut-care
  const pathWithoutLang = stripLocalePrefix(currentPath)
  const newPath = newLocale === 'zh'
    ? pathWithoutLang || '/'           // 中文：无前缀
    : `/${newLocale}${pathWithoutLang}` // 其他语言：/en/...
  localStorage.setItem('locale', newLocale)
  navigate(newPath)
}
```

## 七、翻译工作流

### 7.1 内容优先级

| 优先级 | 内容 | 原因 |
|--------|------|------|
| P0 | 医疗警示、免责声明、隐私政策 | 合规 |
| P1 | 首页、导航、护理指南概述 | 首屏体验 |
| P2 | gut-care 各分节 | 核心干货 |
| P3 | 发心、关于、贡献 | 信任与参与 |
| P4 | 作者长篇经历 | 工作量大，可先摘要 |

### 7.2 翻译原则（健康类）

- **人工审校必选**，机器翻译仅作初稿
- 避免绝对化疗效用语（治愈、根治）
- 保留「请咨询医生」「个人经验」等免责表述
- 药材、食材名注明本地常用叫法（如「罗汉果」英译加学名）
- 敏感内容各语言文化接受度不同，必要时调整措辞

### 7.3 贡献方式

在 `CONTRIBUTING.md` 中增加：

- 翻译文件路径规范
- PR 标题格式：`i18n(ja): translate gut-care fruits section`
- 需母语者或医学背景者复核

## 八、SEO 与元信息

### 8.1 HTML `lang` 属性

```typescript
useEffect(() => {
  document.documentElement.lang = locale === 'zh' ? 'zh-CN' : locale
}, [locale])
```

### 8.2 hreflang（在 `index.html` 或运行时注入）

```html
<link rel="alternate" hreflang="zh" href="https://commonbody.org/" />
<link rel="alternate" hreflang="en" href="https://commonbody.org/en/" />
<link rel="alternate" hreflang="de" href="https://commonbody.org/de/" />
<link rel="alternate" hreflang="es" href="https://commonbody.org/es/" />
<!-- … ja, ko, vi, th, fr 等 … -->
<link rel="alternate" hreflang="x-default" href="https://commonbody.org/" />
```

### 8.3 各语言 title / description

在 `usePageTitle` 或各页面 meta 中按语言切换，避免英文站仍显示中文摘要。

## 九、未完成翻译时的回退策略

当某页面没有目标语言版本时：

```
1. 尝试加载目标语言 Markdown
2. 若无 → 尝试 en
3. 若无 → 使用 zh
4. 页面顶部显示提示条：
   「本文暂无日语版本，当前显示英文版。[阅读中文版]」
```

**不要** 静默显示中文却不告知用户，否则损害信任。
