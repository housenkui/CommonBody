# CommonBody 在历史中的位置

> 本文档说明 CommonBody 所做事情与历史上类似脉络的对照，供「发心」、对外介绍与内部共识参考。  
> 站点链接：**https://commonbody.org**

---

## 一句话概括

**CommonBody 处在「民间病友互助」与「开源公共知识」的交叉点上**——用 21 世纪的网站和短视频，做了一件几百年来都在发生的事：让走过夜路的人，给后面的人点一盏灯。

若非要选一个气质最接近的历史组合，可以说是：

**AA 式同伴互助 + 民国卫生小册子 + 早期互联网病友长帖 + 开源精神**

——四样叠在一起，但还没有一个现成的名字完全等于 CommonBody。

---

## 一、最贴近的核心：康复者教康复者

历史上长期存在一种知识传递方式：**不是机构自上而下宣讲，而是「走过来的人」帮「正在走的人」**。

| 传统 / 运动 | 相似点 |
|-------------|--------|
| **匿名戒酒会（AA，1935 年起）** | 强调亲身经历；不收费、不代表官方医学权威 |
| **艾滋病社群自救（1980–90 年代）** | 官方信息滞后时，患者互相交换护理与就医经验；个人故事改变公众认知 |
| **各病种病友会、慢病互助小组** | 反复发作者最需要「同路人」，而非单次门诊里几分钟的叮嘱 |
| **中国民间「同病相怜、口口相传」** | 村里谁家怎么养、哪个大夫手轻——没有网站，逻辑相同 |

CommonBody 的立场——「每一个康复者都可以成为后来者的灯塔」——放在学术语境里，就是 **互助医疗（mutual aid in health）** 的现代版；载体从村口、病房走廊，变成 **commonbody.org** 与抖音等平台。

## 二、个人苦难写成公共知识

历史上，**一个人的具体遭遇**常被写成可供他人参考的文本：

- **患者回忆录 / 自述**：19 世纪结核病等疾病患者的书信、日记，曾深刻影响社会如何看待疾病——不只有论文在做这件事。
- **民国前后报刊卫生稿**：卫生常识、读者来信、医生答复，很多从**个人遭遇**讲起，再提炼成别人能用的经验。
- **孙思邈等搜集民间验方**：把分散在普通人身上的有效做法**汇总成可传播的知识**。CommonBody 由患者而非大夫发起，但「汇总—传播」的结构相近。

作者将六次手术经历写成长文，再建成公益站，相当于历史上反复出现的一类事：**「一个人的病历」变成「一群人的参考书」**。以前靠刻本与杂志，现在靠 Markdown 与域名。

## 三、非机构、非盈利的知识开源

| 脉络 | 与 CommonBody 的关系 |
|------|----------------------|
| **启蒙时代小册子（pamphlet）** | 廉价、可读，把「该怎么活」直接给普通人，绕过少数机构垄断 |
| **工人互助会、合作社（19–20 世纪）** | 会员分享工伤、职业病、家庭护理；强调**互助而非买卖** |
| **开源软件运动** | 知识可复制、可改、不锁在付费墙里——「人类健康开源计划」即此隐喻在健康经验上的延伸 |
| **维基百科、Appropedia 等** | 普通人贡献、众人使用、维护者审阅；与 v1.0 邮件投稿 + 网站发布结构相近 |

历史上没有 commonbody.org 这个名字，但 **「把有用的东西从少数人手里摊到多数人面前，且不以此牟利」** 这条线很长。

## 四、中国语境里特别像的几件事

### 1. 论坛时代的「经验长帖」（约 2000–2015 年）

天涯、百度贴吧等平台上，肛肠、便秘、术后恢复的长帖非常多，一篇「我的经历」常能帮到陌生人。

**CommonBody 的升级**：把散落、易沉、难检索的帖子，变成有结构、可长期访问、带免责声明与审阅的公益站。

### 2. 「赤脚医生」运动（1960–70 年代）——一半像

- **像**：经验下沉、面向基层、强调可操作的日常护理。  
- **不像**：国家推动的基层医疗体系；CommonBody 是个人发起的民间公益，不替代医疗系统。

### 3. 养生与食疗的民间书写（历代）

《饮膳正要》、各地食疗土方、老人总结的「上火吃什么」——都是从生活实践里长出来的**非处方知识**。强调作息、水果、饮食、排便习惯，落在这条传统里并不突兀。

CommonBody 更现代之处在于：**明确医疗红线**（不诊断、不卖药、重症就医）——历史上民间验方往往边界不清。

### 4. 病友博主与慢病社群（近年）

抖音、小红书上有大量康复者分享。CommonBody 属于其中**更偏公益基础设施**的一支：不只单条视频，而是站点、志愿者招募与长期内容沉淀。

## 五、其他可参考的单人 / 小团队先例

| 人物 / 项目 | 相似处 | 不同之处 |
|-------------|--------|----------|
| **富兰克林等办印刷小册子普及常识** | 个人投入、面向大众 | 多议题出版商；CommonBody 聚焦单一健康议题 |
| **患者推动的 OpenNotes（开放病历）** | 患者参与、拥有自己的病与知识 | CommonBody 侧重经验叙事，非开放医院信息系统 |
| **早期互联网个人健康页（Geocities 等）** | 一人建站、免费浏览 | CommonBody 有 i18n、审阅、志愿者机制，更成体系 |

这些都不是「下一个谁」，而是说明：**历史上一直有人用当时最先进的传播工具，把私人遭遇变成公共礼物。**

## 六、值得警惕的「相似面」（反面教材）

相似的不只是好事，也有教训：

| 历史现象 | 风险 | CommonBody 的应对 |
|----------|------|-------------------|
| **民间验方泛滥** | 有效经验与误导并存 | 免责声明、非医疗定位、重症须就医 |
| **养生谣言与带货** | 借「过来人」卖药卖课 | 非盈利、无带货、志愿者红线 |
| **帖子沉底、知识流失** | 只有故事、没有结构 | 网站沉淀、分类、志愿者与多语言规划 |

## 八、对外介绍可用短段（节选）

> CommonBody 不是第一家做「病友互助」的，也不是第一个分享康复经验的网站。  
> 几百年来，走过夜路的人一直在给后人点灯——从口耳相传，到报刊读者来信，再到贴吧长帖。  
> 我们想用今天最好的工具（网站、开源协作、审阅与免责），把这件事做得更久、更清楚、更少误导。  
> 手术能救急，习惯养根；重症请就医，轻症与反复发作者或许能从同路人的经验里少踩一点坑。
