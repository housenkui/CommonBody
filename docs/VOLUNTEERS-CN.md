> 文档性质：运营内部说明 + 对外招募参考稿  
> 适用范围：中国大陆地区首批志愿者

## 一、为什么需要志愿者

CommonBody（共同体）是一个 **非盈利、面向公众的经验分享网站**。创始人的经历只能覆盖一部分场景；要帮助更多轻症、慢病患者减少反复就医和不必要的花费，需要 **真正走过康复之路的人** 站出来，把日常护理经验整理成可阅读、可传播的文字。

我们在中国大陆招募的第一批志愿者，聚焦 **痔疮及相关肛肠日常困扰的康复经验**——不是医生，不是销售，而是 **愿意无偿帮助别人** 的康复者。

---

## 二、什么是「共同体志愿者」

| | 说明 |
|---|------|
| **身份** | 认同 CommonBody 使命的康复者贡献者，不是雇员，不领取报酬 |
| **主要工作** | 整理并分享亲身康复经验（饮食、作息、运动、就医前后护理、踩坑与教训等） |
| **与「普通投稿者」** | 志愿者愿意 **持续、结构化** 地参与；投稿者可以只发一封邮件。两者内容标准相同，志愿者会有更明确的协作期待 |
| **与「医生」** | 志愿者 **不提供诊断、处方、治疗方案**；不替代医院就诊 |

## 三、基本条件（必须满足）

申请成为志愿者，须 **同时** 符合以下要求：

1. **有痔疮（或肛裂、便秘等肛肠相关）康复的亲身经历**  
   包括：曾患病、曾手术或曾长期困扰，目前已有明显改善或稳定期经验。需能具体描述自己的过程，而非转述他人故事。

2. **愿意无偿帮助他人**  
   不收取 CommonBody 或读者的咨询费、稿费、分成；不以志愿者身份推销产品或服务。

3. **现居中国大陆，或主要生活经验来自大陆日常场景**  
   首批招募侧重国内饮食、就医路径、生活习惯等 **对大陆读者有直接参考价值** 的经验。

4. **年满 18 周岁，具有完全民事行为能力**  
   能独立判断自己分享的内容边界，并对本人陈述负责。

5. **认同 CommonBody 非医疗、非盈利定位**  
   已阅读网站 [免责声明](/disclaimer)、[贡献说明](/contribute) 及本文件中的边界条款。

## 四、我们特别看重的素质（建议具备）

除上述硬性条件外，我们更欢迎具备以下特点的伙伴：

| 素质 | 说明 |
|------|------|
| **诚实、具体** | 写清楚「我做过什么、持续多久、效果如何、是否有个体差异」，避免「包治」「一定有效」 |
| **能区分轻重** | 知道何时应建议读者 **立即就医**，而非一味强调居家护理 |
| **表达清晰** | 文字有条理，读者能照着理解；不要求文学水平，但避免含糊其辞 |
| **尊重隐私** | 不泄露自己或他人的身份证号、病历号、清晰面部照片、详细住址等 |
| **无商业动机** | 不推荐特定医院套餐、药品、保健品、器械、微商产品；若有利益关联须主动声明 |
| **情绪稳定** | 分享是为了帮助他人，而非单纯宣泄；可写痛苦，但应提炼出对他人有用的信息 |
| **愿意被适度编辑** | 维护者可能对文稿做 **错别字、结构、合规用语** 上的修改，会与作者沟通 |

## 五、志愿者可以做什么

- 撰写或整理 **个人康复经历**（可参考网站已有「作者故事」结构）
- 分享 **日常护理方法**：饮食、水果、茶饮、运动、作息、排便习惯、术后恢复等
- 记录 **踩过的坑**（如饮食不当引发便秘、久坐、熬夜、错误信息等）
- 补充 **就医流程中的非医疗经验**（如如何描述症状、何时该挂急诊/肛肠科——仅为个人经历，不构成医疗建议）
- 协助 **审阅其他投稿** 是否明显违背事实或存在推销（在维护者邀请后）
- 参与 **内容分类与标签** 建议（如适用人群、注意事项）

## 六、志愿者不可以做什么（红线）

以下行为 **一律不允许**，违反者将终止志愿者关系：

| 红线 | 说明 |
|------|------|
| **行医或准行医** | 不诊断、不开药、不指定手术方案、不替代医生做「该不该手术」的判断 |
| **推销与导流** | 不推广医院、诊所、药品、保健品、智能马桶、坐垫等产品；不放二维码、微信号引流卖货 |
| **虚假与夸大** | 不编造经历、不抄袭他人文章、不夸大疗效、不使用「根治」「百分百」等用语 |
| **伤害性内容** | 不鼓励延误重症治疗；不传播未经证实的「偏方」；不发布违法信息 |
| **侵犯他人** | 不公布他人隐私；不人身攻击其他患者、医生或机构 |
| **有偿服务** | 不以 CommonBody 志愿者名义私下收费咨询、带货、办培训营 |
| **代表官方** | 不得自称「CommonBody 员工」「官方认证医生」；志愿者身份不等于网站医学背书 |

全站须始终保留醒目提示：

> **重症患者不适用，必须立即就医。本站内容仅供参考，不能替代专业医疗。**

志愿者发布或审阅内容时，须主动强化这一原则。

## 七、内容与合规注意事项（中国大陆）

在中国大陆开展公开内容协作，还需注意：

1. **互联网信息服务**  
   网站内容为公开信息。志愿者稿件须符合法律法规及公序良俗，不涉及政治敏感、色情、迷信治病等违规内容。

2. **医疗广告与营销**  
   不得变相发布医疗广告；不得使用「最有效」「国家级」「医生推荐」等违规表述（参见《医疗广告管理办法》及相关规定的精神——本站本身非医疗机构，更应谨慎）。

3. **中医药与食疗表述**  
   可写个人饮食、茶饮体验，但避免 **宣称治疗功效**；使用「对我有帮助」「我当时的做法」等经验语气，而非「能治」「能治好」。

4. **手术与医院信息**  
   可写「我在某年于某地做过手术」的个人经历，但 **不推荐具体医院、医生、价格套餐**；避免引发医疗纠纷风险。

5. **图片与病历**  
   不要上传带姓名、医院名称、检查单号的清晰病历照；思维导图、饮食照片等须确保无他人隐私入镜。

6. **版权**  
   引用他人文章、图片须注明出处；提交内容视为授权 CommonBody **非盈利、免费展示**，保留作者署名（可用笔名）。

## 九、如何申请

### 9.1 发送邮件至

**[housenkui@gmail.com](mailto:housenkui@gmail.com)**

邮件主题建议：`【共同体志愿者申请】+ 笔名或姓名`

### 9.2 邮件中请包含

1. **自我介绍**（年龄区间、所在省份即可，无需精确地址）  
2. **康复经历摘要**（患病时间、是否手术、目前状态，约 300～800 字）  
3. **你愿意分享的方向**（如：术后恢复、饮食、久坐办公、孕期/产后如有相关经验等）  
4. **一篇样稿或提纲**（可先发经历中的一个具体片段）  
5. **确认声明**（可复制填写）：

```
本人确认：
- 上述经历为本人真实体验；
- 本人愿意以非盈利方式参与 CommonBody 内容建设；
- 本人理解本站不提供医疗诊断与治疗，重症须就医；
- 本人同意内容经审阅后发布，并可能被适度编辑。
```

### 9.3 审核流程

1. 维护者阅读申请（通常 **7～14 个工作日** 内回复，人手有限请谅解）  
2. 通过后沟通 **1～2 篇** 首批稿件主题  
3. 定稿发布至 commonbody.org，标注版本与贡献者笔名  
4. 后续按志愿者本人时间与维护者计划逐步更新  

**未通过不表示经历无价值**，可能只是现阶段与网站方向、表述规范尚未匹配；仍欢迎以普通投稿方式分享。

## 十三、常见问题

**Q：我没做过手术，只是长期保守调理好了，可以申请吗？**  
A：可以。手术与否不是硬性门槛，关键是 **真实、可复用的日常经验**。

**Q：我是医护人员，可以作为志愿者吗？**  
A：可以以 **个人康复者或患者家属** 身份分享生活经验，但不得在站内以执业身份提供诊疗建议，也勿暗示「专业医疗背书」。

**Q：志愿者需要露脸或录音吗？**  
A：不需要。文字为主即可。

**Q：我的经历里用过某品牌产品，能写吗？**  
A：尽量避免品牌名；若对理解必不可少，应声明 **无商业利益关联**，且不作购买推荐。

**Q：将来会收费或接广告吗？**  
A：CommonBody 当前定位为 **非盈利公益项目**；若未来政策变化，将提前说明并尊重志愿者选择是否继续。
