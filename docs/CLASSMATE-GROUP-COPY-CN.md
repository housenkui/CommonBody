# 大学同学群分享文案

> 适用于微信同学群（约 60 人规模）。非盈利公益，官网：**https://commonbody.org**  
> 原则：**像跟老同学唠嗑，不像发广告**；愿意看就看，愿意聊就私聊。

---

## 一、发群主文案（推荐，约 200 字）

```
各位老同学，好久不见 👋

跟大家汇报个小事：这几年我做过六次痔疮手术，后来才慢慢想明白——手术能救急，但长期还是要靠作息、饮食、排便习惯这些日常调整。从 2013 年最后一次手术到现在，十几年没再动刀了。

我把这些年的经历和踩过的坑，整理在一个 **纯公益网站** 上了，叫 CommonBody（共同体）：
https://commonbody.org

打开点「作者经历」就能看到我的完整故事；都是个人经验，**不卖课、不带货、不收费**，仅供参考，重症还是要去医院。

要是你或身边有人有类似困扰，当个参考就行；不方便点链接，浏览器里输入 commonbody.org 也可以。

有想细聊的，私聊我就行，别在群里尴尬 😄
```

4. 久坐、搬重物、劳累要注意

我完整经历在 commonbody.org，写得比较细。你方便可以说说大概情况，我按自己的踩坑经历帮你理理思路——个人经验，不能替代医生。

## 八、发群前的实用建议（62 人群）

| 建议 | 说明 |
|------|------|
| **选时间** | 晚上 8～10 点或周末上午，大家较有空 |
| **只发一条** | 主文案发一次即可，别连发链接+长文+图片，像刷屏 |
| **可配一张图** | 网站首页截图或思维导图（可选），增加可信度 |
| **@ 人要谨慎** | 62 人群不要 @所有人，容易惹人烦 |
| **红包不必** | 同学群分享公益，发红包反而像推广 |
| **准备好私聊** | 真正会问的多半私信你，群里公开回复用第四节、第五节 |
| **尴尬就自嘲** | 结尾加「别在群里尴尬」「划过就行」降低压力 |

## 九、不建议在同学群说的话

- ❌ 「请大家帮忙转发到朋友圈」——像拉票  
- ❌ 「这个项目一定能帮到你」——太绝对  
- ❌ 「手术没用，靠作息就行」——易引争议  
- ❌ 连续几天在群里提网站——打扰  
- ❌ 把医学敏感图、手术细节直接发群——不适

## 十一、邀请关系好的同学来网站分享（抖音私信）

> 场景：大学同学，有**强直性脊柱炎**等康复经历，抖音互关，想请他给 CommonBody 写经验稿。  
> 原则：**先朋友、后项目**；不施压；强调可笔名、可只写一篇。

### 第一轮私信（轻松开口，推荐）

```
老同学，抖音老看到你，想起大学那会儿你强直性脊柱炎挺不容易的，后来看你状态好多了，一直挺佩服你怎么扛过来的。

我这些年折腾痔疮手术，后来做了个纯公益网站 commonbody.org，把经历免费放上去。现在除了我自己的故事，也想请真正走过康复路的人一起写——**不是卖课、不带货、不给钱**，就是给后面的人留个参考。

你愿不愿意挑几段**你愿意讲**的经历，整理成一篇？饮食、运动、作息、就医路上踩过的坑都行。可以用笔名，写多少你定，我帮你排版上线。

要是愿意，咱们找个时间语音聊半小时，我帮你理提纲；不愿意也完全 OK，咱还是老同学 😄
```

### 第二轮（他回复「可以考虑 / 怎么写」）

```
太好了，不急，你方便的时候弄就行。

你可以按这个粗提纲想（不用全写）：
1. 大概什么时候确诊、当时什么状态（一句带过即可）
2. 哪些日常习惯对你有帮助（运动、睡眠、饮食、保暖等）
3. 踩过什么坑、什么对你没用
4. 想对还在疼的同学说的一句话

写法：**写「我做过什么」**，别写「一定能治好」；强直这块更要写清——该听风湿科医生的还得听医生，咱们只是补日常经验。

发我邮箱就行：housenkui@gmail.com
主题写：【投稿】强直性脊柱炎经验 + 你的笔名
也可以先微信/抖音发我草稿，我帮你看一眼再定稿。
```

### 他犹豫「我写得不好 / 怕误导别人」

```
完全理解，这个本来就要谨慎。

你不用写得多专业，就写**你自己试过的事**，加一句「因人而异、遵医嘱」。网站上有免责声明，我也会帮你把容易违规的表述改掉。

你哪怕只写 500 字「我坚持什么、避免了什么」，对同病的人可能就是一盏灯。写不出来也没事，别有压力。
```

### 他问「有没有报酬 / 是不是志愿者」

```
没有报酬，纯公益。志愿者和投稿都行——你忙的话**投一篇稿**就够了，不用长期义务。

发表用笔名、可模糊年份和医院名，隐私你说了算。
```

### 语音聊之前，你可准备的 3 个问题

1. 现在主要靠什么稳住状态？（运动/药/作息，以他愿意说的为准）  
2. 如果回到刚确诊那年，你最想听到哪条**非处方**的生活建议？  
3. 有什么是你特别想提醒新人「别信偏方 / 别硬扛」的？

### 邀请时建议别说的

- ❌ 「帮我撑场面」「网站缺内容」——像利用朋友  
- ❌ 「你比医生还懂」——合规风险  
- ❌ 在同学大群 @ 他公开邀请——社死，改私聊  
- ❌ 一次发五条长消息——像推销
