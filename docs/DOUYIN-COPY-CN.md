## 五、常见问题跟评话术

**评论区短回：**

手术不是没用，该做的时候得做。我六次里也有必须上手术台的时候。

但对我个人来说，反复犯病，是因为手术后没把作息、饮食、排便习惯改过来——光切肉球，根子还在。

现在十几年没再手术了，靠的是日常调整。详细经历在 **commonbody.org**，有兴趣可以看看，都是我自己踩的坑。

**私信可加长：**

你说得对，手术肯定有用，急性期、严重的时候不能硬扛。

我反思的是：我那几年短时间内做了太多次，每次好了又熬夜、劳累、便秘，很快又犯——不是手术没用，是我没把后面的事做好。

所以我现在跟别人说：**手术救急，习惯养根**。你要是正在纠结要不要手术，这个得听医生的；要是术后老复发，可以看看我网站里怎么调整的。

## 使用建议

| 场景 | 推荐版本 |
|------|----------|
| 评论区跟评 | 短版或更短版 |
| 有人主动私信 | 私信完整版 |
| 对方已表示兴趣、想快速回复 | 私信精简版 |
| 被质疑手术 / 广告 / 可信度 | 第五节对应话术（优先用评论区短回） |
| 对方症状严重 | 第五节第 5、9 条，先建议就医 |

- 链接尽量单独一行，方便对方复制
- 若对方问「怎么加你」，再单独发语音沟通方式；首条尽量不直接留微信号（抖音对导流较敏感）
- 重症、出血不止等情况，务必建议先就医
- **跟评忌**：和人吵架、绝对化（「手术没用」「一定能好」）、贬低医生或医院
