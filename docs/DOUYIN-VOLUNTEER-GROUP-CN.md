# 抖音「共同体志愿者」群简介与群公告

> 适用于已入群的志愿者协作群。非盈利公益项目，官网：**https://commonbody.org**  
> 与 `docs/VOLUNTEERS-CN.md` 配套使用；对外招募仍以邮件 **housenkui@gmail.com** 为准。

---

## 一、先分清：群简介 vs 群公告

| | 群简介 | 群公告 |
|---|--------|--------|
| **作用** | 外人点进群资料时第一眼看到 | 成员进群后、日常置顶提醒 |
| **篇幅** | 宜短（建议 **80～150 字**） | 可稍长，但建议 **分段、可扫读** |
| **语气** | 一句话说清「这是什么群、谁适合进」 | 说清规则、分工、红线、怎么协作 |
| **更新频率** | 少改 | 有规则变化时及时改 |

**原则：** 简介负责「吸引人且筛人」；公告负责「管住群、护住品牌、护住志愿者自己」。

## 三、群公告（完整版，可直接复制置顶）

```
欢迎加入 CommonBody（共同体）志愿者群 🙏

【我们是谁】
这是一个非盈利公益项目的志愿者协作群。
官网：https://commonbody.org
使命：让康复者的真实经验，帮助更多人少踩坑、少花冤枉钱。
首批聚焦：痔疮及相关肛肠日常困扰（便秘、肛裂、术后护理等）。

【你是谁】
你已通过邮件审核入群，身份是「康复者贡献者」——
不是雇员，无报酬；不是医生，不能开方诊断。

【群里可以做什么】
✅ 交流个人康复经历与日常护理（饮食、作息、运动、排便习惯等）
✅ 讨论稿件怎么写：结构、用词、哪些该写、哪些别写
✅ 互相提醒：重症要就医、别夸大疗效、别推销
✅ 向维护者反馈：网站问题、选题建议、待整理的经验点
✅ 使用笔名，保护隐私

【群里禁止做什么（红线）】
❌ 诊断、开药、推荐手术方案（准行医）
❌ 推销医院、药品、保健品、器械、课程；发二维码/微信号卖货
❌ 编造经历、抄袭、夸大（「根治」「百分百」「最有效」）
❌ 泄露他人或自己的身份证、病历号、详细住址
❌ 以志愿者名义私下收费咨询、带货、办培训
❌ 人身攻击、引战、发与公益无关的广告

【全群须牢记】
⚠️ 重症患者不适用，必须立即就医。
本站及本群内容仅供参考，不能替代专业医疗。

【协作方式（当前 v1.0）】
· 定稿、发布：以邮件与网站为主（housenkui@gmail.com）
· 群内：讨论、提纲、互相把关、日常答疑
· 发布前：维护者会做错别字、结构、合规用语审阅，会与作者沟通
· 志愿者可随时申请退出，维护者也可终止严重违规者

【发言建议】
· 用「我当时的做法」而非「一定能治好」
· 写清个体差异：对我有用，不代表对所有人有用
· 不确定是否该写进网站时，先在群里问一句

【关于隐私】
本群为工作群，请勿随意截图外传。
不要未经允许转发他人病史细节。

——
但行好事，莫问前程。
每一个康复者，都可以成为后来者的灯塔。
```

## 六、书写要点（为什么这样写）

### 1. 群简介要「筛人」

抖音上有人误以为是病友群、问诊群、带货群。简介里写清：

- **志愿者协作群**（不是随便聊天的患者群）
- **非盈利、非医疗**
- **官网域名**（建立信任）

### 2. 群公告要「护人」

志愿者在群里若给了像诊断一样的建议，或有人开始推销，风险在 **志愿者本人** 和 **CommonBody 品牌**。公告里红线写清楚，日后处理有据。

### 3. 平台敏感点（抖音）

| 注意 | 建议 |
|------|------|
| 导流卖货 | 公告明确禁止二维码、微信号推销 |
| 医疗资质 | 反复强调「非医生、不诊断」 |
| 群被举报 | 不发偏方、不承诺疗效、不攻击医院医生 |
| 外链 | 简介可写 `commonbody.org`；群内少反复刷屏链接 |

### 4. 和官网招募说明保持一致

群内规则应与 `docs/VOLUNTEERS-CN.md` 第六节「红线」一致，避免「群里一套、网站一套」。
